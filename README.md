## Projects

### 1. Netflix Data Analysis — Python

Analyzed a dataset of 8,790 Netflix titles to explore content distribution, country-wise associations, release-year trends, content ratings, and genres. Completed as part of the Data Analysis Using Python Internship at Auspify Technologies.

**Key findings:**
- Movies account for 69.69% of the titles.
- TV-MA is the most common recorded content rating.
- International Movies is the most common genre category.
- The United States has the highest number of country-title associations.
- 2018 is the year with the highest title count in the dataset.

**Tasks completed:** Data cleaning, content type analysis, country analysis, release-year trends, rating and genre analysis, and an interactive business intelligence dashboard.

**Tools used:** Python, pandas, Matplotlib, Plotly, CSV, HTML.
